# KB 工作台 · Chrome 新标签页

0.15.8 采用经过交互预览确认的 Orbit 工作台：文件夹主页、顶部入口、底部信息状态栏、居中完整设置与知识面板。Motion 14.6.0 本地打包，使用轻盈弹簧进入、快速淡出位移；文字与窗口保持尺寸，退出完成后才从 top layer 关闭。原有设置、收藏、分组、拖拽、图标缓存、检查工具、备份及同步逻辑完整保留。

## 加载与连接

1. 打开 Chrome 的 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”。
2. 选择本目录（包含 manifest.json）。也可以解压构建的 chrome-kb-0.15.8.zip，选择其中 chrome-kb 文件夹。
3. 打开新标签页，点击“设置”中的“NAS 连接”，或知识库中的连接入口，填写 kbcli 服务地址及**用户令牌**。待办和阅读需要 kbcli 0.1.2+，含网站图标的自动备份与多设备同步需要 0.1.5+；NAS 的服务地址由部署者提供。
4. Chrome 请求访问 NAS 主机时允许该地址。用户令牌来自 NAS 的 kbcli/service.env 中 KBCLI_USER_TOKEN，agent 令牌不能用于此页面。

设置与缓存仅保存在 chrome.storage.local，不使用 Chrome 账号同步；令牌不返回给新标签页的数据快照，不写入知识库或安装包。Chrome 本地存储不是加密密码库。更换服务地址需要重新填写令牌；断开连接会清除凭据与缓存，并移除该连接的主机授权。

Chrome 的主机权限按主机匹配，不能限定到具体端口。插件向设置中指定的 NAS 服务地址和固定 API 路径发请求；加载自定义图标时，还会按用户点击请求其填写的图片直链；不跟随重定向，不发送网页 cookie。[Chrome 主机权限说明](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)。

## 网站收藏与设置

- 点击“收藏网站”，填写名称、HTTP/HTTPS 网址并选择分组；不带协议的网址默认使用 HTTPS。
- 点击文件夹查看该组网站；支持新建和重命名分组。“管理”显示分组排序与编辑按钮，文件夹内的网站箭头调整组内顺序。搜索期间禁用网站排序，清空搜索后可调整。
- 卡片右下角“⋯”编辑网站、修改所属分组或删除收藏。删除分组会将网站移入默认分组，保留网站内容；默认分组可以重命名、不能删除。
- 主页输入框按名称、域名及完整网址筛选收藏；按 Enter 或点击搜索按钮使用所选搜索引擎，输入时不向外发送查询。文件夹内支持组内搜索。图标仅在创建或手动编辑时获取并随收藏保存；打开、刷新或离线重载新标签页都不请求网站图标，不接第三方图标服务。
- 设置面板支持“在新标签页打开网站”“显示知识库入口”和“紧凑收藏布局”。点击外部遮罩、按 Escape 或关闭按钮均可收起。
- 收藏与分组独立保存在本机 chrome.storage.local，未连接 NAS、NAS 离线或断开连接均可使用；暂不读取 Chrome 原生书签，可自动备份到知识库并由 NAS 推送 Gitee，不使用 Chrome 账号同步。
- 可导出 JSON 备份并在另一设备导入；合并保留现有数据，按分组名称匹配，同组相同网址去重。导出不包含 NAS 地址、令牌、展示缓存或显示偏好。导入文件上限 16 MiB，最多 100 个分组、2000 个网站。
- 多标签页共享同一份收藏。收藏与 NAS 使用独立请求队列，后台分别串行处理，版本改变时拒绝旧表单覆盖、保留输入；核对后可再次保存。

所有文章、文件夹、收藏编辑、分组编辑、待办和设置弹窗均支持点击外部关闭；嵌套时仅关闭最上层。保存或连接进行中会阻止误关；关闭设置同时清空令牌输入。统一使用可取消的关闭请求、指针起点与边界判断，并等待退出动画结束，从内部拖动到外部不会误关。

## 背景与个性化

- 顶底栏默认融入壁纸：入口和信息不再使用独立浅色卡片，边缘渐隐遮罩保护浅色文字。设置 → 外观与背景可关闭“顶底栏融入壁纸”恢复实色栏；“文字高光”仍独立控制。

- 默认背景 assets/mist.svg 是本项目绘制的山雾矢量插画，离线可用；内置山雾、暮色、深夜三种色调。
- 设置中上传 PNG、JPEG 或 WebP（原图最大 15 MiB、4000 万像素）；浏览器缩至最长边 2560px 并重新编码 WebP，保存的数据 URL 不超过 2 MiB。SVG、GIF 与非支持内容会拒绝；文件名或浏览器报告的类型不符时，按实际 PNG/JPEG/WebP 内容识别后重编码。不请求外部壁纸服务。
- 支持遮罩 0–75%、模糊 0–16px、居中/顶部/底部位置、时钟开关与必应/Google/百度搜索。图片位置和搜索引擎均使用直接点击的原生单选组，也可用方向键切换；设置立即保存。色调也会作用于上传的背景。
- 图片及外观单独保存在 appearance，不影响原 navigation 或 NAS 连接；跨标签页更新检查版本。存储失败时保留旧值，图片不随旧版收藏文件导出；自动备份会以去重附件上传 NAS。恢复默认保留收藏与连接。
- 首次打开不预置示例收藏；截图中的网站仅来自隔离测试。旧版 navigation v1 和连接配置原样沿用。

## 知识库操作约定

- 默认收起知识库，点击顶部入口展开；桌面和窄屏均为原生模态居中面板，覆盖在主页上方，收藏与时钟布局不移动。点击外部遮罩、按 Escape 或关闭按钮均可收起。三个页签分别为待办、知识、状态。
- “知识”提供最近 20 篇文档和手动搜索。点击文章打开居中的只读阅读弹窗，读取当前 Markdown 文件；关闭后保留列表位置，支持 Escape 或外部点击关闭。
- 阅读支持标题、强调、删除线、引用、列表、只读任务清单、表格、代码块和安全链接；不提供编辑或保存。元数据不混入正文，同名首标题避免重复；相对 Markdown 链接可继续阅读库内文章。
- HTML 按文字展示，不执行脚本。图片以链接或附件提示展示，不自动加载外部图片；本地附件、数学公式与 Mermaid 图暂未接入。文章正文不进入离线缓存，不会因阅读发送写入请求。搜索结果会标识索引待更新。
- 在右侧查看待处理、进行中、已完成和全部待办（全部中包含已取消项）；可按标题和标签查找。
- 新增填写标题、可选日期与标签。修改支持标题、日期、标签及执行状态；清空日期会移除截止日期。
- 完成使用列表勾选按钮，单独发送用户完成请求，保留原有内容审核状态，无需再次人工审核。已完成任务可通过编辑重新打开。
- 修改携带显示版本的文件哈希，编辑表单同时绑定打开时的连接版本；其他标签页切换 NAS 或重新保存连接后会保留草稿并禁止向新连接提交。冲突时保留草稿、显示服务端最新摘要并阻止覆盖；用户可明确选择载入最新内容再编辑。
- 网络失败时保留有时间戳的展示缓存，禁用写入。写请求失败不会自动重放；若保存结果不确定，先刷新核对。
- 页面可见时每 30 秒刷新，也可手动刷新。自动同步暂停时仍允许保存到 NAS，并提示尚不会推送。
- 自动同步只展示状态，不提供绕过暂停或强推入口。具体冲突在 NAS 处理，人工恢复按部署文档执行。

## 状态接口

使用 `/api/tasks`、`/api/status`、`/api/autosync`，以及已有的 `/api/recent`、`/api/search`、`/api/read` 只读知识接口。知识库 API 返回当前认证角色，连接时必须确认 human；同步状态接口是只读的，服务端通过 KBCLI_AUTOSYNC_STATE_DIR 配置库外调度状态目录。

未配置目录显示“同步状态尚未接入”，读取失败、未启动、重试、暂停和心跳过期分别展示，不当作正常运行。Git 跟踪分支对齐不代表此刻已再次访问远端，页面会显示最近成功同步时间。内容格式正常也不等于内容已人工批准。

## 构建和验证

在项目根目录运行：

```bash
python3 scripts/build_extension.py
node --test tests/extension/*.test.mjs
uv run pytest -q
```

构建生成 dist/chrome-kb 与 dist/chrome-kb-0.15.8.zip。已有输出不会覆盖，重新构建请使用新的输出父目录，例如 --output dist/rebuild/chrome-kb（归档文件按版本命名）。构建只包含白名单资源，不打包测试 mock、凭据、缓存或本机环境。

浏览器交互的独立测试环境：

```bash
uv run python tests/extension/serve_fixture.py --workspace /tmp/kbcli-ui-test --port 18767
```

访问 http://127.0.0.1:18767，使用同一地址及测试用户令牌 ui-test-user。这是本机隔离知识库，Chrome API 在测试页面中由 shim 模拟，不是实际扩展加载环境；请勿在此测试页填写正式令牌。正式扩展包不包含 shim。

当前工具环境不支持通过 CDP 加载未打包扩展，因此自动化已覆盖页面、客户端、后端及 NAS 只读连接，尚需在真实 Chrome 中按上述步骤加载并确认主机访问权限。升级已有插件时，在 chrome://extensions 点击重新加载，随后重新打开新标签页即可；不要移除扩展，以保留浏览器中的数据。若浏览器另外请求本地网络访问，请按其提示授予 NAS 访问，不要关闭浏览器安全检查。

## 自动备份与恢复（0.5.0）

需要 NAS kbcli 0.1.3。设置 → 知识库自动备份：开启自动备份并填写设备名称，或立即备份。收藏、分组、浏览偏好、搜索引擎与自定义背景按设备保存，离线时保留本机内容，重新打开浏览器后补传。用户令牌与连接信息不会进入备份。

“查看备份与恢复”可预览任意设备快照，确认后替换本机数据；操作前先存本机撤销副本。上传成功仅代表已保存到 NAS，Gitee 推送状态看知识库侧栏。新增 alarms 权限，不依赖新标签页一直打开。详情及限制见[备份设计](../../docs/chrome-backups.md)。

## 自定义控件（0.5.1）

开关、分段选项、滑轨和输入框使用统一自定义样式。网站分组和待办状态使用自定义浮层列表；截止日期可输入 YYYY-MM-DD 或在自定义日历选择。支持方向键、Home/End、Enter、Escape，日历还支持 PageUp/PageDown 切月。菜单关闭后返回原控件；“已完成”仍通过待办完成按钮执行。Chrome 120+ 无需额外依赖或权限。

## 多设备自动同步（0.6.0）

需要 NAS kbcli 0.1.4。连接同一知识库后，自动共享收藏、分组、顺序和外观配置；地址、令牌、设备名称、同步与备份开关保留在各设备。右上角显示同步状态，可进入设置立即检查。

离线编辑保留在本机，运行/唤醒后重试。并发修改保守暂停：先保存双方版本，再由用户预览后接收共享内容或发布本机内容。原自动备份、恢复和撤销继续使用。首次接入已有不同收藏的电脑也会要求处理冲突，不直接替换。[详细机制与限制](../../docs/chrome-workspace-sync.md)。

## 网站图标与拖动整理（0.7.0）

网站采用紧凑图标网格，名称最多两行，悬停显示域名；文件夹预览也显示网站图标。新增 favicon 权限，由 Chrome 提供图标；只传网站来源，不传查询参数与片段。图标缺失时仍可使用首字入口，图标不进入备份或共享数据。

悬停或键盘聚焦时出现拖动手柄，拖动分组可改变首页顺序，拖动网站可改变组内顺序。“整理”模式显示跨组投放区域，将网站手柄拖到目标分组即可移动；全部网站视图支持在分组网格之间拖动。触屏显示手柄；可聚焦手柄后使用方向键排序，跨组也可通过编辑表单选择分组。搜索期间禁用排序。

放下后一次保存，保留 navigation v1 与现有备份/共享协议。其他标签页在拖动期间有更新时拒绝旧版本，保留最新内容并提示。更新已有插件时沿用原加载目录并重新加载，不要移除插件，以保留收藏与连接。

图标优先使用 Chrome 缓存；遇到默认地球图标或缓存不可用时，尝试网站自身来源下的 /favicon.ico，失败回退首字。图片请求使用 no-referrer，不包含收藏原网址中的路径、查询参数与片段，不接第三方聚合图标服务。网站图标仍由浏览器缓存，不进入 NAS 备份或共享数据。


## 固定上下区域与独立滚动（0.7.1）

主页品牌栏、时钟搜索区、收藏操作栏和底栏保持在视口内，只有中间的分组/网站列表滚动。分组弹窗固定标题、关闭按钮与搜索工具栏，只有内容区滚动。滚动区域可通过 Tab 聚焦后用键盘滚动；滚轮到达边缘不会带动整页。拖动靠近列表边缘仍可自动滚动。小屏和矮窗口缩减顶部留白，不更改收藏或显示偏好。


## 图标复用与分组开关（0.7.2）

本页面首次可见时按网站来源加载一次图标，共享给文件夹预览、展开网格和搜索结果；成功与失败结果都保留在本页内存中。后续开关分组、搜索、排序或管理不重复检查同一来源。图标以已解码位图绘制，重绘时直接复用，手动刷新或重新打开页面才重新检查；不将图标位图放进 NAS 备份。

打开文件夹只更新弹窗，保留主页原节点；同一分组内容未变化时再次打开也保留原网格和滚动位置。收藏有真实修改时仍更新显示。分组弹窗使用稳定浅色表面，关闭缩放、延迟退出和叠加背景模糊，避免开关时的浅色闪烁；嵌套编辑、Escape、外部关闭和焦点返回继续由原生 dialog 处理。


## 手柄显示（0.7.3）

普通鼠标模式仅在悬停或键盘焦点可见时显示拖动手柄和网站编辑入口；鼠标关闭弹窗后即使焦点返回原分组，移走鼠标也会隐藏。隐藏的手柄不拦截点击。管理模式、键盘 Tab 操作与无悬停触屏仍提供入口。


## 持久图标缓存（0.8.0）

首次可见时获取图标，解码成功后保存至当前浏览器的独立 Cache Storage。新标签页直接读取已保存的图片响应，不重新检查来源；缺失图标也保存结果。持久缓存与本页位图复用配合，不再每开新页重新下载图标。

手动刷新页面会重新检查可见图标；设置 → 收藏数据 → **更新网站图标** 会检查所有收藏的网站来源，最多四个来源并发，期间保留现有显示，完成后更新。获取失败时不覆盖旧的可用图标。新标签页会读取最新成功保存的版本。缓存不定时过期，由浏览器管理其存储配额；主动清除扩展数据或浏览器回收缓存后需重新获取。

没有新增权限。只允许收藏中已有网站的来源，网络路径固定为 /favicon.ico 或 Chrome 内置 favicon 接口；不带网页路径、查询参数、Cookie 或 referrer。跨域不透明响应保留原有安全边界，只交给图片元素解码，不读取其正文。候选图片通过解码后才发布为共享缓存，旧请求不能覆盖较新的缓存。浏览器存储失败不影响收藏。

图标仅保存在当前浏览器，不进入 NAS 收藏备份、共享同步或 Git 远端。删除收藏后，后续后台清理会移除不再使用的图标记录。


## 直接拖动卡片（0.8.1）

分组和网站支持直接按住图标、名称或卡片主体拖动，无需先悬停找到手柄。桌面移动超过 8px 才启动，普通点击继续打开。编辑/前后移动控件不会触发拖动。触屏按住约 250ms 后再移动可拖动，直接短滑继续滚动列表。搜索期间保持禁排；跨组投放和边缘自动滚动沿用原逻辑。

普通鼠标悬停不再显示多余的拖动标志；方向键入口在键盘焦点或管理模式下保留，触屏仍提供操作入口。图标持久缓存、收藏存储与 NAS 接口不变。


## 拖出分组投放首页（0.9.0）

直接按住网站图标拖动，越过分组窗口边缘后显示首页文件夹。拖到其他文件夹，目标会高亮并显示名称，松手即移入目标分组。无需先点整理；普通模式收起横向目标栏，整理模式仍可使用它。

分组较多时，拖到中间收藏区域的上下边缘可自动滚动，也可在拖动时使用滚轮。顶部和底部保持固定。松手落在空白处、原分组或按 Esc 均取消移动并恢复原分组；成功后留在首页。拖动期间其他标签页更新收藏时拒绝过时写入并提示重试。

[验收记录](../../docs/verification/chrome-home-folder-drop-0.9.0.md)。

## 悬停展开并选择位置（0.9.1）

网站拖到首页目标文件夹后停留约 0.65 秒，会自动展开目标分组。继续拖到网站之间，绿色插入线显示松手后的实际位置；支持列表开头、中间、末尾及空分组，松手才保存。目标网站较多时可在列表上下边缘自动滚动或使用滚轮。成功后目标分组保持展开，便于检查顺序。

快速经过不会展开，直接松手仍可移入分组末尾。展开后将图标拖出窗口可返回首页换一个目标；按 Esc、放到列表标题或窗口外空白区域会取消，不改变原位置。原分组拖拽节点在整个过程中保留，取消后恢复原列表和滚动状态。

## 工具栏快速收藏（0.10.0）

点击浏览器工具栏 KB 图标直接打开约 400px 的原生小弹窗，预填当前网页名称、完整网址和浏览器图标；可以修改名称、搜索分组、直接新建分组并保存。上次成功选择的分组会被记住。已收藏网址进入编辑模式，保存原 ID；保留完整路径、查询参数与片段。

图标有三种来源：自动获取、图片链接、1～2 字文字图标及底色。图片链接点击“加载”后预览，成功才替换；失败或拒绝授权保留当前图标，也可继续保存网站。加载中的图片若还未完成，本次保存保留当前图标。图片以 128px、最大 32 KiB WebP 嵌入单条收藏，总图标容量上限 1 MiB；再次打开不请求远程图片。选定图标在弹窗中“手动获取图标”或重新加载图片链接时更新，不被普通新标签页渲染覆盖。

草稿在输入时交给后台保存，关闭或重新打开弹窗可以继续编辑；最多保留 10 个页面上下文的草稿，7 天内可恢复。切换图片来源或手动修改后，迟到的自动结果不会覆盖输入。保存有稳定操作 ID 与版本检查，弹窗关闭或响应丢失后重试不会重复创建；其他标签页修改时保留输入，核对后再次保存。

新标签页“编辑网站”中的“编辑图标”会在当前工作台打开同一个快捷编辑器弹窗，不创建标签页。弹窗内“打开工作台”仍可进入首页。Chrome 设置页等受限页面显示手动填写入口。

权限：activeTab 在用户点击工具栏时临时读取当前页面；scripting 仅提取顶层网页标题与图标链接，不读取正文或表单内容。图片链接按点击申请对应主机权限，网络请求不携带 cookie/referrer，不跟随跳转，输入源文件上限 2 MiB。浏览器权限按主机而非端口授权。

自定义图标跟随 JSON 导出、导入、恢复和共享同步。同步含图标的收藏需要 NAS kbcli 0.1.5，并建议各设备使用 Chrome 插件 0.10.0；旧 NAS 拒绝新字段时，本机收藏保留。这里仅更新代码，不自动部署 NAS。[验收记录](../../docs/verification/chrome-capture-0.10.0.md)。

## 保存后关闭与原地编辑（0.10.1）

工具栏快捷收藏在后台确认保存成功后自动关闭；验证失败、存储失败或版本冲突时保留弹窗及输入。工作台的“编辑图标”在原页面的模态弹窗中完成，带入基础编辑表单中尚未保存的名称、网址和分组。保存后关闭编辑框、刷新原卡片，底层分组仍保持展开。

支持关闭按钮、Esc 与外部点击；分组下拉展开时，第一次外部点击只收起下拉。保存进行中暂时阻止误关闭，失败后恢复可关闭状态。取消不保存收藏，输入仍按原规则保留为草稿。弹窗关闭后焦点回到原卡片或搜索框。[验收记录](../../docs/verification/chrome-capture-close-0.10.1.md)。

## 图标只在创建或手动编辑时获取（0.11.0）

网站图标在创建时获取并保存成 WebP；无法获取则固定保存文字图标。之后无论打开新标签页、刷新、分组开关、排序还是离线重载，都只展示已保存数据，不检查图片来源、不自动补图、不按缓存失效重试。改名、修改分组或普通网址编辑也不会重新获取图标。需要更换时，在网站“编辑图标”中点击“手动获取图标”、加载图片链接或设置文字图标。设置中的批量更新入口已移除。

旧收藏升级时只读取已有本机缓存，将可读图片固定到收藏；缺失或不可读缓存固定为文字，不联网补齐。已有手动图标保持原样，导入缺少图标的旧文件使用固定文字。图标随收藏导出、备份和同步；本次不新增 NAS 数据字段或升级要求，仍使用 kbcli 0.1.5 的图标支持。

favicon.mjs / favicon-store.mjs 仅保留作历史测试，当前 UI 不再导入，发布包不再包含这两个自动加载模块。旧 Cache Storage 保留；icon-snapshots.mjs 只做本机读取升级，不请求任何网站。[验收记录](../../docs/verification/chrome-frozen-icons-0.11.0.md)。


## 手动网站可用性检查（0.12.0）

首页收藏工具栏点击“检查网站”，再点“开始检查全部收藏”。首次需要允许插件访问收藏对应的网站主机；拒绝不会开始检查。没有新增安装时必选权限，不申请常驻全网授权。每次最多 4 个 GET 请求，单次 12 秒超时，只读取最多 64 KiB 正文后停止读取，不发送 Cookie 或 referrer。临时会话参数链接只请求站点根入口，并在结果中明确标注范围。

检查在后台继续，弹窗可关闭；进度及结果仅存在当前浏览器，不同步 NAS、不进入收藏导出。worker 暂停后利用已有 alarms 权限恢复已手动开始的任务（30 秒过期 claim），不会自行创建新任务。打开/刷新新标签页只读取最近结果，不重新检查或获取图标。

默认展示异常和待确认项；可切换全部结果。状态包括可访问、跨域跳转、HTTP 异常、访问受限、连接失败、超时、未检查和停止。显示检查时间、分组、HTTP 状态与说明。卡片显示最近状态；网址改动后旧结果标为“待重查”，禁止用旧结果批量删除。

异常不会自动勾选。勾选后点击“核对并删除所选”，核对名称并确认才批量删除；收藏版本或网址已改变会整体拒绝。删除与本机撤销副本原子保存；可撤销最近一次批量删除，期间若已有其他收藏修改则禁止撤销覆盖。删除会按现有收藏同步设置同步到其他设备。

检查只反映本次网络环境下的入口响应，不能确认登录后功能或证明网站永久失效。403、429、验证码及跨域跳转限制可能是访问限制；浏览器 fetch 无法可靠细分 DNS、TLS 证书和 CORS 原因，统一标为连接失败并提示浏览器复核。不会绕过证书警告或代解验证码。


## 一键获取全部网站图标（0.13.0）

首页“获取图标”（或设置 → 收藏数据 → 批量获取网站图标）打开工具，点击“一键获取全部图标”后申请对应网站主机授权并开始。默认保护自定义图片和文字图标，勾选“同时替换自定义图标”可尝试替换全部；旧版没有图标来源字段，文字图标通过是否与当前标题、网址生成的默认首字/颜色完全一致来判断，默认样式相同的手动文字无法区分。

每批最多 4 个请求，同一批次相同站点共享一次获取。优先请求站点根目录 `/favicon.ico`，失败后尝试 Chrome favicon 服务，并排除其默认图标；失败、权限不足、解码失败或存储容量不足均保留原图标。不使用第三方图标聚合服务，不发送收藏路径、查询参数、Cookie 或 referrer。图标转为 128×128 WebP，沿用单个 32 KiB、总计 1 MiB 限制。

进度和逐站结果仅本机保存，可筛选失败和跳过项。后台队列支持关闭弹窗继续、停止、worker 租约恢复；仅继续用户已开始的任务，不会自动创建任务。获取期间手动修改图标、网址或删除收藏会跳过旧请求结果；名称、分组、排序保持当前版本。保存后的图标沿用现有导出、NAS 备份和多设备同步能力。

新标签页打开、刷新、展开分组仍只使用固定图标，不自动重新获取。只有用户点击批量工具、创建收藏或在编辑器手动获取时才触发图标获取。


0.13.1 修复 Chrome 内部 favicon 响应缺少 Content-Type 时被误拒绝的问题。仅内部响应按文件签名识别 MIME，外部图片链接仍需有效图片类型、授权与大小校验。


## 请求受限与图标优先级（0.14.0）

网站检查将 HTTP 异常与待复核分开统计。401/403/429、验证码、登录跳转、跨域/地址空间/网络原因未明、超时和跨站跳转均不作为失效依据，界面禁止勾选删除，后台也拒绝这些状态的批量删除（包括旧版保存的 networkError）。只有 HTTP 错误响应可勾选，再核对确认清理。

根据用户反馈，内置有限的已知跳转提示：Flow → flow.google.com、Google Cloud → accounts.google.com、CodeCV → www.codecvcv.com、蓝点网 → www.landian.news、Roxi → www.roxi123.us。这些只是授权重试提示，不证明跳转永远不变，不自动更新收藏。请求失败且目标未授权时，显示明确的目标主机；用户点击授权后才重试这一个原收藏入口，拒绝授权保留结果。CORS 错误本身不向 JavaScript 暴露目标地址，未知目标仍需手动打开复核；不申请全网权限。

批量图标改为先读 Chrome _favicon，排除默认图标后成功即保存，不向网站请求 favicon、无需额外网站权限；Chrome 无可用图标时，仅尝试已授权站点的 /favicon.ico。缺少权限的失败项可点“授权失败站点后重试”，只请求对应失败主机权限。不会在打开新标签页时自动创建获取任务，失败保留原图标，自定义保护保持不变。

## Orbit 界面与阅读

设置分成外观与背景、动效体验、搜索与浏览、收藏管理、备份与同步、NAS 连接。原有字段、表单与后台消息保持兼容，没有删除旧设置或迁移收藏。深浅配色、减少动态效果和文章字号属于新增加的本机界面偏好，保存在独立的 workbenchInterface，不改变既有备份/共享载荷的校验格式。

待办筛选、搜索和结果数量保持固定，结果列表单独滚动。新增、完成、编辑、冲突处理、断网只读与日期/状态浮层沿用原逻辑。知识列表用文档类别、更新时间、路径和搜索摘要展示；文章用限宽正文、固定工具栏、目录跳转、三档字号和阅读进度。文章继续只读；不请求远程文章资源，不运行文章 HTML。系统 prefers-reduced-motion 优先，手动减少动态效果可跨标签页同步到本机其他工作台页面。

首页与分组内的网站状态采用 favicon 右下角的 SVG 标记，不再在名称下面增加状态文字。勾号表示可访问，锁/时钟/跳转箭头表示待复核，感叹号表示 HTTP 异常；悬停显示原因与检查时间，未检查时不显示。详细检查报告继续保留文字与原有删除保护。输入框统一为单层聚焦边框，日期和搜索等复合控件由外框显示聚焦；错误字段保留错误色。

“设置 → 外观与背景”新增“文字高光”（默认关闭）和“顶底栏融入壁纸”（默认开启）。前者控制浮动文字的光晕；后者移除整条顶底栏的底色和分隔线，以小面积信息衬底保持可读。关闭融入效果可恢复实色栏。两项随本机界面偏好保存，即时生效，不改变壁纸文件和遮罩设置；系统强制颜色模式保留可读的系统色背景。
