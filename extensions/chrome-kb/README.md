# KB 工作台 · Chrome 新标签页

0.4.1 将新标签页改为山雾背景、居中时钟与搜索、磨砂分组文件夹；知识库从右侧按需展开，设置使用独立抽屉。采用 Manifest V3，无需安装前端构建依赖；Markdown 解析器随扩展本地打包，无远程脚本、统计服务或内容脚本。

## 加载与连接

1. 打开 Chrome 的 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”。
2. 选择本目录（包含 manifest.json）。也可以解压构建的 chrome-kb-0.4.1.zip，选择其中 chrome-kb 文件夹。
3. 打开新标签页，点击“设置”中的“知识库连接”，或知识库中的连接入口，填写 kbcli 服务地址及**用户令牌**。需要 kbcli 0.1.2+；NAS 的服务地址由部署者提供。
4. Chrome 请求访问 NAS 主机时允许该地址。用户令牌来自 NAS 的 kbcli/service.env 中 KBCLI_USER_TOKEN，agent 令牌不能用于此页面。

设置与缓存仅保存在 chrome.storage.local，不使用 Chrome 账号同步；令牌不返回给新标签页的数据快照，不写入知识库或安装包。Chrome 本地存储不是加密密码库。更换服务地址需要重新填写令牌；断开连接会清除凭据与缓存，并移除该连接的主机授权。

Chrome 的主机权限按主机匹配，不能限定到具体端口。插件只向设置中指定的服务地址和固定 API 路径发请求；不跟随重定向，不发送网页 cookie。[Chrome 主机权限说明](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)。

## 网站收藏与设置

- 点击“收藏网站”，填写名称、HTTP/HTTPS 网址并选择分组；不带协议的网址默认使用 HTTPS。
- 点击文件夹查看该组网站；支持新建和重命名分组。“管理”显示分组排序与编辑按钮，文件夹内的网站箭头调整组内顺序。搜索期间禁用网站排序，清空搜索后可调整。
- 卡片右下角“⋯”编辑网站、修改所属分组或删除收藏。删除分组会将网站移入默认分组，保留网站内容；默认分组可以重命名、不能删除。
- 主页输入框按名称、域名及完整网址筛选收藏；按 Enter 或点击搜索按钮使用所选搜索引擎，输入时不向外发送查询。文件夹内支持组内搜索。图标以网站名称首字本地生成，不向第三方图标服务发送浏览记录。
- 设置抽屉支持“在新标签页打开网站”“显示知识库入口”和“紧凑收藏布局”。点击外部遮罩、按 Escape 或关闭按钮均可收起。
- 收藏与分组独立保存在本机 chrome.storage.local，未连接 NAS、NAS 离线或断开连接均可使用；暂不读取 Chrome 原生书签，不通过 Gitee 或 Chrome 账号同步收藏。
- 可导出 JSON 备份并在另一设备导入；合并保留现有数据，按分组名称匹配，同组相同网址去重。导出不包含 NAS 地址、令牌、展示缓存或显示偏好。导入文件上限 16 MiB，最多 100 个分组、2000 个网站。
- 多标签页共享同一份收藏。收藏与 NAS 使用独立请求队列，后台分别串行处理，版本改变时拒绝旧表单覆盖、保留输入；核对后可再次保存。

所有文章、文件夹、收藏编辑、分组编辑、待办和设置弹窗均支持点击外部关闭；嵌套时仅关闭最上层。保存或连接进行中会阻止误关；关闭设置同时清空令牌输入。Chrome 134+ 使用原生 closedby，Chrome 120–133 使用按边界判断的兼容处理，从内部拖动到外部不会误关。

## 背景与个性化

- 默认背景 assets/mist.svg 是本项目绘制的山雾矢量插画，离线可用；内置山雾、暮色、深夜三种色调。
- 设置中上传 PNG、JPEG 或 WebP（原图最大 15 MiB、4000 万像素）；浏览器缩至最长边 2560px 并重新编码 WebP，保存的数据 URL 不超过 2 MiB。SVG、GIF 与格式不符的文件会拒绝；不请求外部壁纸服务。
- 支持遮罩 0–75%、模糊 0–16px、居中/顶部/底部位置、时钟开关与必应/Google/百度搜索。图片位置和搜索引擎均使用直接点击的原生单选组，也可用方向键切换；设置立即保存。色调也会作用于上传的背景。
- 图片及外观单独保存在 appearance，不影响原 navigation 或 NAS 连接；跨标签页更新检查版本。存储失败时保留旧值，图片不随收藏备份导出，也不上传 NAS。恢复默认保留收藏与连接。
- 首次打开不预置示例收藏；截图中的网站仅来自隔离测试。旧版 navigation v1 和连接配置原样沿用。

## 知识库操作约定

- 默认收起知识库，点击右侧入口展开；桌面和窄屏均为原生模态悬浮抽屉，覆盖在主页上方，收藏与时钟布局不移动。点击外部遮罩、按 Escape 或关闭按钮均可收起。三个页签分别为待办、知识、状态。
- “知识”提供最近 20 篇文档和手动搜索。点击文章打开居中的只读阅读弹窗，读取当前 Markdown 文件；关闭后保留列表位置，支持 Escape 或外部点击关闭。
- 阅读支持标题、强调、删除线、引用、列表、只读任务清单、表格、代码块和安全链接；不提供编辑或保存。元数据不混入正文，同名首标题避免重复；相对 Markdown 链接可继续阅读库内文章。
- HTML 按文字展示，不执行脚本。图片以链接或附件提示展示，不自动加载外部图片；本地附件、数学公式与 Mermaid 图暂未接入。文章正文不进入离线缓存，不会因阅读发送写入请求。搜索结果会标识索引待更新。
- 在右侧查看待处理、进行中、已完成和全部待办（全部中包含已取消项）；可按标题和标签查找。
- 新增填写标题、可选日期与标签。修改支持标题、日期、标签及执行状态；清空日期会移除截止日期。
- 完成使用列表勾选按钮，单独发送用户完成请求，保留原有内容审核状态，无需再次人工审核。已完成任务可通过编辑重新打开。
- 修改携带显示版本的文件哈希，编辑表单同时绑定打开时的连接版本；其他标签页切换 NAS 或重新保存连接后会保留草稿并禁止向新连接提交。冲突时保留草稿、显示服务端最新摘要并阻止覆盖；用户可明确选择载入最新内容再编辑。
- 网络失败时保留有时间戳的展示缓存，禁用写入。写请求失败不会自动重放；若保存结果不确定，先刷新核对。
- 页面可见时每 30 秒刷新，也可手动刷新。自动同步暂停时仍允许保存到 NAS，并提示尚不会推送。
- 自动同步只展示状态，不提供绕过暂停或强推入口。具体冲突在 NAS 处理，人工恢复按部署文档执行。

## 状态接口

使用 `/api/tasks`、`/api/status`、`/api/autosync`，以及已有的 `/api/recent`、`/api/search`、`/api/read` 只读知识接口。知识库 API 返回当前认证角色，连接时必须确认 human；同步状态接口是只读的，服务端通过 KBCLI_AUTOSYNC_STATE_DIR 配置库外调度状态目录。

未配置目录显示“同步状态尚未接入”，读取失败、未启动、重试、暂停和心跳过期分别展示，不当作正常运行。Git 跟踪分支对齐不代表此刻已再次访问远端，页面会显示最近成功同步时间。内容格式正常也不等于内容已人工批准。

## 构建和验证

在项目根目录运行：

```bash
python3 scripts/build_extension.py
node --test tests/extension/*.test.mjs
uv run pytest -q
```

构建生成 dist/chrome-kb 与 dist/chrome-kb-0.4.1.zip。已有输出不会覆盖，重新构建请使用新的输出父目录，例如 --output dist/rebuild/chrome-kb（归档文件按版本命名）。构建只包含白名单资源，不打包测试 mock、凭据、缓存或本机环境。

浏览器交互的独立测试环境：

```bash
uv run python tests/extension/serve_fixture.py --workspace /tmp/kbcli-ui-test --port 18767
```

访问 http://127.0.0.1:18767，使用同一地址及测试用户令牌 ui-test-user。这是本机隔离知识库，Chrome API 在测试页面中由 shim 模拟，不是实际扩展加载环境；请勿在此测试页填写正式令牌。正式扩展包不包含 shim。

当前工具环境不支持通过 CDP 加载未打包扩展，因此自动化已覆盖页面、客户端、后端及 NAS 只读连接，尚需在真实 Chrome 中按上述步骤加载并确认主机访问权限。升级已有插件时，在 chrome://extensions 点击重新加载，随后重新打开新标签页即可；不要移除扩展，以保留浏览器中的数据。若浏览器另外请求本地网络访问，请按其提示授予 NAS 访问，不要关闭浏览器安全检查。

## 依赖与部署边界

NAS 服务可以在库外独立 Python 环境运行 0.1.2，旧版 skill/远端 CLI 保持协议兼容。更新服务不要求把软件升级写成知识内容，也不自动升级电脑上的 skill。插件不启动 Git 调度器，现有 NAS 自动同步仍由独立服务负责。
