# 第二版：文件夹桌面与固定信息栏

对应三项反馈的修订：去掉侧边栏，恢复文件夹弹窗；全局状态下移；关闭时消除缩小、挤压和排版跳变。

## 视觉方向

保留深空蓝灰、雾银与冰蓝。首页改为更安静的文件夹桌面：不再给每个文件夹套一块实体卡片，悬停才提供弱表面反馈。收藏区域居中，上方只保留时钟和搜索。主页面不承载同步、保存和维护的状态文案。

固定底栏分成四段：收藏总量、保存与备份状态、当前浏览/操作/任务反馈、演示说明及详情入口。弹窗遮罩不覆盖底栏，状态仍可阅读；原生模态窗口保持正确焦点隔离。工具的逐项检查结果仍在详情窗口内，全局任务进度和停止操作在底栏持续呈现。

## 文件夹弹窗

- 同主题、居中固定外框，顶部名称和关闭，内部搜索及快速切组，中间网站网格独立滚动，底部添加入口。
- 在弹窗内切换文件夹不改变外框。网站编辑复用同一窗口，避免“弹窗套弹窗”。
- Escape 在编辑中先返回分组；分组浏览时再按一次才关闭。
- 普通外部点击关闭整个当前窗口；从窗口内拖动/选中文字后移出不误关闭。
- 主页滚动位置和底栏位置不受弹窗影响。

## 关闭策略

第一版 `dialog[open]` 同时承担结构布局和显示状态，关闭时结构规则先撤掉，而 display/overlay 过渡还留着窗口，flex 纵向布局可能退回横向。这是内容拥挤的根因之一。

第二版把结构规则放在持续生效的 dialog 基础层；关闭开始时读取外框宽高并冻结，保留原生 open 状态；只做 120ms opacity 淡出，完成后才调用 close，随后释放临时尺寸。不使用 scale、translate、宽高或 blur 动画，也不在淡出时卸载内部内容。

外部点击、Escape 和关闭按钮统一进入这条流程。重复关闭合并为同一请求；减少动效时直接关闭，并保证不会留下过期 Promise 阻止后续关闭。

长任务窗口也固定尺寸，结果新增只增加内部滚动内容，不撑大外框。知识库侧面板在离场时同样只淡出，并在底栏上方留出空间。

## 逐帧验收

文件夹、独立编辑、设置、知识库、新建分组、工具和手机文件夹均已采集关闭期间的动画帧，宽高变化均为 0，布局始终为 column，位置和内容起点也保持不变。覆盖外部点击、Escape、关闭按钮，另验证减少动态效果后再恢复动画仍能关闭。

文件夹内搜索和切组可用，编辑与文件夹共享完全相同外框；390×844 下弹窗不超出视口且不盖住底栏。演示工具关闭后仍在底栏继续进度，可从底栏停止。

这些测量只证明本轮原型的离场布局稳定性，不等同于正式插件的完整帧率或功能验收。正式接入时仍需回归草稿、保存、拖拽与备份恢复逻辑，不直接叠加原型样式到旧 CSS 上。
