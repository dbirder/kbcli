# KB 工作台 · 第二版原型

方向：没有侧边栏的文件夹桌面，文件夹用居中弹窗浏览，全局信息集中到底部状态栏。

预览：http://127.0.0.1:18829/ 。本轮是独立设计原型，不是已安装插件的新版本，不连接真实收藏与 NAS，编辑只作用于演示内存。

```bash
cd /Users/dbirder/workspaces/project/知识库工具/kbcli
python3 -m http.server 18829 --bind 127.0.0.1 --directory design/kb-orbit-v3
```

## 本轮针对三项反馈的变化

1. 去掉左侧分组栏，恢复文件夹桌面；点击文件夹打开同主题弹窗。弹窗内可搜索、切换分组和编辑网站，主页面不切走。
2. 数量、保存、同步、当前浏览和任务进度集中到固定底栏，取消悬浮提示。底栏在弹窗打开时仍清楚可见；操作反馈也通过面板内不可见的 live region 传递给辅助技术。
3. 关闭统一为 120ms 的透明度淡出，不缩放、不位移。淡出期间保留原生 open 状态和全部布局属性，冻结窗口外框，结束后才 close。外部点击、Escape 和关闭按钮复用同一条关闭流程。

## 关闭挤压的根因

第一版把 `flex-direction: column` 绑定在 `dialog[open]`。关闭后 open 属性移除，但 display/overlay 离散过渡仍保留窗口的显示；其纵向布局却先失效，子内容可能退回 flex 默认横排，从而出现缩小、拥挤的视觉。

第二版把结构布局放到稳定的 dialog 基础规则，关闭时不卸载内容、不改窗口类型；离场只改变 opacity，结束后再关闭并释放尺寸。任务窗口固定外框，列表在内部滚动，也避免进度新增行改变窗口高度。

这是针对布局生命周期的修正，不是通过减慢动画掩盖问题。

## 交互边界

- 文件夹与其编辑视图共享同一外框；Escape 在编辑视图先返回分组，第二次才关闭文件夹。
- 恢复确认仍在设置内部局部展开，Escape 只取消该确认。
- 桌面主体仅收藏区域滚动，文件夹只内容区滚动；页脚固定。
- 所有全局状态集中底部；网站检查详情中的逐项结果仍保留在工具内，便于核对。
- 工具演示关闭后可继续在底栏显示进度，底栏可停止任务。
- 开关弹窗仍是演示；没有真实图标获取、网页跳转、拖拽和 NAS 操作。

第一版保留在 `design/kb-orbit-v2`，可对比方向，不覆盖它。
