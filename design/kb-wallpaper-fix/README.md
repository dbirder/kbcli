# 0.15.3 背景图片修复

根因分为两个独立问题：

1. workbench.css 将默认壁纸透明度设为 0.09，另叠加 70%–92% 的界面色渐变，导致内置背景几乎不可见。现在默认和上传背景统一使用正常图片透明度，仅按已保存的遮罩设置显示。
2. 用户提供的「【哲风壁纸】剑客-水墨.png」实际文件头为 FF D8 FF，file/sips 均识别为 2560×1440 JPEG。原 prepareWallpaper 按 File.type 的 PNG 分支校验，误拒绝了这个可正常解码的文件。现在先识别受支持的实际 PNG/JPEG/WebP 文件头，再按实际 MIME 解码、限制像素并重编码 WebP；不修改原文件。

隔离浏览器已使用指定原文件验收：上传后 2560×1440，约 153 KB 字符的 WebP 数据 URL；刷新、第二标签页内容一致。三个色调、0/75/24% 遮罩、6/0px 模糊、上/下/居中位置通过。拒绝 SVG 上传后保留已存图片，原有收藏和连接数据未变化。详见 browser-qa.json 和 previews/。

新增三个本地格式识别、格式与扩展名不符、损坏及超限内容测试；前端测试共 141 项通过，打包测试通过。用户图片仅用于运行时测试与截图，不作为扩展静态资源打包。
