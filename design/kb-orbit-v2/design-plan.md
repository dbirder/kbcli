# KB 工作台：轨迹设计方向

目标：一个每天打开多次的个人入口。90 余个收藏、15 个分组、知识库、备份维护需要有序共存；科幻感服务于清晰、稳定与专注。

## 视觉基础

| Token | 深色 | 用途 |
|---|---|---|
| 底色 | #0D1420 | 稳定画布 |
| 一级表面 | #141E2C | 导航、搜索与面板 |
| 二级表面 | #1C2A3B | 控件、悬停 |
| 结构线 | #2A3B50 | 分区与焦点边界 |
| 正文 / 次要 | #E8EEF7 / #A2B1C5 | 信息层次 |
| 强调色 | #A5C6F4 | 选中、主要操作 |

字体：macOS 使用系统 SF / 苹方，Windows 使用 Segoe UI / 微软雅黑；时钟使用同一字体的 tabular-nums，不加载网络字体。正文 14，次要 12，标题 22，时钟 54。间距基于 4/8px，圆角由 8/12/18px 表达控件、卡片和面板层级。

## 布局

固定顶部 68px；可折叠的 208px 分组导航；中间唯一主内容滚动区；固定轻量状态栏。

```
品牌与导航        搜索快捷键                  知识库 / 设置
分组导航          时钟与搜索（紧凑，高度固定）
总览、15 个分组    当前分组面包屑 / 数量 / 工具 / 添加
                  分组总览 或 当前分组网站网格
本机与同步状态    预览说明
```

总览继续提供文件夹；左侧导航适合频繁切换，可以折叠。进入分组仅替换内容区域，顶部和背景不移动。搜索输入后直接筛选收藏，输入框和焦点不重建。

## 方案自检与修订

初始想法中的全屏星空、发光网格和旋转轨道会抢占日常入口的注意力，已删去。只保留搜索区域背后的静态极淡弧线，其他区域通过对比、网格对齐和节制留白建立品质感。大时钟缩小，工具按钮收进菜单，减少横向拥挤。避免所有区域都被同样的玻璃圆角卡片包裹。

本轮只做独立设计原型，不修改扩展安装目录、存储格式、NAS 或用户收藏。原型用公开演示网站，保存只在页面内存中生效。
