# 首屏闪烁修复 · Chrome 0.15.6

原来 HTML 会先加载山雾背景，主模块读取保存配色后才重构顶底栏，最后通过后台读取用户壁纸和收藏。默认深色、默认壁纸、未完成的页面布局可能出现在不同绘制帧。

现在 head 中的本地 startup.js 在 CSS 和 UI 解析前读取可丢弃配色缓存；MV3 保留原 CSP，未使用内联脚本。壁纸使用不超过 32 KiB 的本地 WebP 缩略预览铺底，原始 appearance 和图标保存方式不变。删除 HTML 默认图片 src，保存壁纸解码和本机收藏布局完成后解除首屏保护，不等待 NAS 请求。壁纸解码最多等待 1.2 秒，模块异常 4 秒解除保护；缓存失败不影响设置。

验证：

- Node 146 项通过，含新增 5 项首屏缓存/异常/幂等测试；打包测试 1 项通过。
- 隔离浏览器模拟 appearance.get、navigation.get 各 800ms 延迟：290 个等待帧全部使用保存配色和壁纸预览，不显示中间布局。首次完整可见帧壁纸已解码、时钟及文件夹和底栏都准备完成。
- 连续 3 次正常打开约 161ms、85ms、80ms 就绪；仅为本机隔离环境测量，不代表所有机器的启动耗时。
- 深色首屏、390px 窄屏、模块被阻断后约 4 秒回退均通过。收藏和外观载荷逐字比对不变。
- 真实 Chrome 重载确认 0.15.6，连续两次新标签页显示正常，保留水墨壁纸、15 个分组、90 个收藏和 NAS 连接。

首屏保护解决插件内部的主题/壁纸/布局切换；浏览器创建标签页到开始解析扩展文档之前的浏览器画面由 Chrome 管理。
