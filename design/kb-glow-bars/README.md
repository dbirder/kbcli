# 0.15.4 文字高光与顶底栏

- “设置 → 外观与背景”增加文字高光（默认关闭）与顶底栏融入壁纸（默认开启）两个开关。
- 光晕仅由开关决定。顶底栏去掉全宽底色与分隔线，信息和按钮使用小面积衬底，壁纸覆盖完整视口。关闭融入可恢复原实色栏。
- 两项属于 workbenchInterface 本机显示偏好，支持即时更新、重开和其他本机标签页同步。不改 navigation、appearance、connection、workspace 或 backup 数据格式。
- 旧的深浅配色、减少动态效果、阅读字号保留；系统强制颜色模式使用 Canvas / CanvasText 回退，不依赖壁纸或阴影来保证信息可读。
- 隔离浏览器检查了鼠标和 Space 键开关、重开、第二标签页、深浅配色、390px 固定底栏、强制颜色模式；书签、背景和连接载荷对比未变。见 browser-qa.json。
- Chrome 实机已重载为 0.15.4，并实际开启/关闭文字高光；最终保持高光关闭、顶底栏融入开启。已有壁纸与 15 个分组、90 个收藏保留。
