kbcli v0.1.1 软件模块

CLI / HTTP / skill 已实现 · Python 共用核心 · Git 显式同步 · MCP 为后续可选

统一命令与角色

  • • Typer CLI 默认 JSON；远端 CLI 通过 /api/command 白名单调用同一核心，无任意 shell。
  • • 本地 actor 为来源声明；HTTP 根据用户与 agent 的不同 Bearer 令牌确定角色。

规范与模板已落地

  • • 显式参数 → 文档声明 → 路径规则 → 目录绑定 → 默认值，最终受 allowed 限制。
  • • tasks、sources 和项目概览严格校验；非严格范围的旧笔记允许正文检索并报告提示。

检索与引用可追溯

  • • 中文 bigram + FTS5/BM25，属性筛选；literal/grep 核验原文，返回行号与全文件哈希。
  • • fresh 只覆盖本地文件；索引与 Git 分别报告状态，合成实验不代表真实语料性能。

索引与只读状态

  • • serve/watch 使用周期全哈希核验，无文件事件监听；新增、删除和改名更新索引。
  • • status 只观察已有状态；缓存不可读时返回未知，不创建空索引或自动恢复操作日志。

受控写入与 Git 边界

  • • operations.py 负责预期哈希、锁、原子写入与持久日志；用户完成任务保留原审核状态。
  • • 写入不自动提交；sync 只快进，工具提交需日志证明；未知修改与分叉留待人工处理。

发布与后续阶段

  • • 完整 skill 包携带代码、锁定依赖及文件哈希；安装器在库外准备环境，支持更新回滚。
  • • 当前待补 NAS 部署、Chrome 插件和 Hermes 联调；MCP、批准入口和自动 Git 调度未实现。
