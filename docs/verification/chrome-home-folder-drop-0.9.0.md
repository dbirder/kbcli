# 首页文件夹跨组投放验收（0.9.0）

日期：2026-10-20。

## 设计

原生 modal 保持打开，只在拖出窗口后隐藏窗口表面并透明化背景，保留顶层拖动预览与提示。首页仍 inert，使用实际可见文件夹几何位置识别目标；松手重新命中，避免复用过期高亮。收藏中间区域负责滚动，上下固定区域不移动。空白、原分组、Esc、pointercancel/touchcancel 不写入。

## 验收

Ego TaskSpace 15，隔离 loopback fixture 18790，仅合成收藏；未用真实收藏做拖拽写入。

- 1280×900：网站从开发工具拖出窗口，学习阅读高亮、名称提示正确；松手移动成功，12 个收藏总数不变，弹窗关闭且留在首页，无多余标签页。
- 空白处、原分组、Esc 三种取消：revision 不变，原分组保持打开，拖动态和高亮清除。
- 48 个分组：拖至收藏区域底部自动滚动至 scrollTop 372，window.scrollY 保持 0；投放新出现的文件夹成功，总数保持 12。
- 分组内普通拖拽排序成功。拖动期间模拟其他标签页更新 revision：新版本保留，提示收藏已更新，不覆盖并发数据。
- Node 测试 86/86；扩展打包白名单测试 1/1；JS 语法和 git diff --check 通过。
