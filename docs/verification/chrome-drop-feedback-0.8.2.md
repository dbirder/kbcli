# 直接跨组与拖动反馈验收（0.8.2）

日期：2026-10-20。

## 改动与定位

- 分组展开即显示固定的跨组投放栏，不依赖整理模式；多分组时横向滚动，搜索期间禁排并收起目标。
- 原卡片 transform 0.2s 过渡被拖动预览继承。测量发现 inline transform 已到 matrix(...,300,30)，computed transform 仍为零且有运行中的 CSSTransition，导致预览跟随滞后。现在仅对 sort-floating 禁用过渡/动画，周围卡片仍由 Sortable 让位。
- 预览移到当前 dialog 顶层子节点（主页为 body），避免受列表滚动裁切，保留 Canvas 像素并提供阴影。原位为明确空白虚线框。
- 投放按钮固定尺寸，实际插入占位隐藏，避免撑大目标。高亮按指针和当前目标栏几何位置更新；滚动后松手按实际位置确定分组，栏外/间隙不会接受过时目标。

## 验证

- Node 86/86；Python 白名单打包 1/1；node --check 与 git diff --check 通过。
- Ego 隔离 fixture 18789，初始 3 个分组、14 个合成网站，后扩充至 21 个分组。
- 整理 aria-pressed=false 时，跨组栏已显示“常用、学习阅读”。直接拖入“常用”成功，总数保持 14。
- 修复预览过渡后，鼠标点 (744.34375,453.234375) 位于浮动预览矩形 x=694.4214 / y=414.2344 / w=99.84375 / h=114 内；预览父节点为 folder-dialog，transition-property=none，排序保存正确。
- 目标高亮时投放区仍为 118×42px，没有被网站卡片撑大。
- 390px 页面无横向溢出，目标栏高度 54px、可视宽 316px、内容宽 2158px，网站内容仍有 445px 高度。
- 拖到目标栏边缘可自动横向滚动至 scrollLeft=1720。追加 Node 几何回归：指针静止而目标栏滚动后改选新目标，栏外和间隙返回空目标；释放按该目标保存，避免沿用旧 DOM 插入分组。
- 浏览器输入测试没有误开新页，测试空间维持 1 页。正式收藏未用于排序/跨组写入测试。
