# 固定上下区域与独立滚动验收（0.7.1）

日期：2026-10-19。

主页采用动态视口高度的纵向 flex 布局。品牌栏、时钟搜索、收藏操作栏和底栏不参与列表滚动；collection-scroll 占用剩余空间。分组弹窗使用固定标题/工具栏与 folder-scroll 内容区。两处滚动区域提供键盘焦点、稳定滚动条槽位和 overscroll-behavior:contain。手机与矮窗口减少顶部留白，手机底部预留知识库入口的位置。

## 验证

- Node 75/75 通过；Python 白名单打包测试 1/1 通过；git diff --check 通过。
- Ego 隔离数据：36 个分组、90 个网站，其中开发工具分组含 72 个网站。
- 1280×800 时，文档总高度为 800，中间列表可视高度 349、内容高度 1246。真实滚轮使列表滚动，时钟、收藏操作栏、底栏位置不变，window.scrollY 为 0。
- 72 个网站的弹窗内滚轮使 folder-scroll.scrollTop 达到 893；标题 y=55、工具栏 y=156.796875 保持不变，dialog.scrollTop 和 window.scrollY 都为 0。
- 真实手柄拖动至列表底部触发自动滚动，collection-scroll.scrollTop 达到 50，window.scrollY 为 0，底栏 y=752 不变。
- 390×844 时，文档尺寸为 390×844，中间列表可视高度 403、内容高度 2056；底栏位于 y=770、高 74。分组弹窗滚动区高度 563、内容高度 3124。
