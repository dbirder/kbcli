# 请求受限保护、跳转授权重试与 Chrome 图标优先级

日期：2026-10-22。版本：0.14.0。

## 行为

- 检查结果分为可访问、HTTP 异常、待复核、未检查/已变更。401/403/429、验证、登录、跨域/地址空间/网络原因未明、超时和跨站跳转不作为失效依据。
- 界面禁用待复核项目删除勾选，后台 audit.delete 也拒绝这些状态；旧版 networkError 同样受到保护。只有 HTTP 错误响应参与勾选核对删除。
- 已知跳转目标使用有限精确来源表。用户点击明确的目标主机授权按钮后才重试所选原入口；拒绝授权不改动结果，不修改收藏 URL。来源通过 URL 规范化和精确匹配，Origin API 可用时使用结构化比较，Chrome 120 使用 new URL 回退；拒绝用户信息、不同协议/端口和相似前缀。
- 已知提示仅涵盖用户报告的 Flow、Google Cloud、CodeCV、蓝点网和 Roxi；不意味着自动发现所有重定向。未知 CORS 目标无法从 fetch 异常获得，仍需人工复核。Google 登录响应保持待复核。
- 批量图标先使用 Chrome _favicon，有有效图标时不发起站点请求或申请网站权限；缺少缓存时仅回退已授权站点。失败主机可明确授权后重新尝试。默认自定义保护、失败保留、持久化和无自动获取保持不变。

## 验证

- Node 扩展测试：137/137 通过。
- Python 发布白名单测试：1/1 通过。
- 隔离 UI：原有检查、选择/取消/确认/撤销/停止/旧 URL 保护通过，受限项已禁用选择。
- 隔离 UI：已知跳转请求失败显示目标授权按钮；拒绝不发第二次请求，允许后只重试原选中入口，结果为跨站跳转并继续保持不可删除；收藏完整数据未改变。
- 隔离 UI：图标主机权限请求被拒时，Chrome 图标仍能获取；外部回退授权拒绝保留图标，允许后保存结果；并发手动编辑优先、持久化、停止与窄屏测试通过。
- 测试空间和本机服务已关闭，测试仅使用合成数据。
- 原生 Chrome 扩展详情页已确认加载 0.14.0，工作台保持 15 个分组、91 个收藏。
- 原生现有报告（原任务 100 项，当前其中 9 项已删除）显示：79 个可访问、0 个当前 HTTP 异常、12 个待复核、9 个未检查/已变更。Mistral、Google Flow、Google Cloud、CodeCV、Roxi、超时与内网站点均显示待复核且不可勾选删除。
- Flow、Google Cloud、CodeCV、Roxi 等旧结果已显示明确目标主机的授权重试按钮。本轮只读核对，未新增网站授权、未运行真实全站检查、未修改/删除收藏或批量替换图标。
