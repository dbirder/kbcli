# 图标复用与分组白闪验收（0.7.2）

日期：2026-10-19 至 2026-10-20（Asia/Shanghai）。

## 原因与改动

原实现打开文件夹会调用主页 render，replaceChildren 重建整个收藏区；每个预览和网站又新建 img，重新检查 Chrome favicon 与网站 favicon。改为只更新文件夹内容，按 revision / 分组 / 搜索 / 整理状态复用相同网格；相同 revision 的存储通知不重绘。

favicon 按来源共享一个本页缓存和加载 Promise，保留解码位图与失败结果。命中时同步绘制 Canvas；首次可见时由 IntersectionObserver 触发。大小图标共用 64px 位图，避免重复检查。跨域图像只绘制、不读取/导出像素。手动刷新/重新打开页面会建立新缓存，不增加永久存储或 NAS 字段。拖动克隆同步复制 Canvas 像素，避免预览图标消失。

分组弹窗原有缩放和 220ms 延迟退出叠加两层背景模糊；现在改为稳定不透明表面、即时开关，取消该弹窗的顶层退出尾帧与滤镜合成。其他编辑/设置弹窗的交互保持原规则。

- 真实手柄拖动时，浮动预览 Canvas 与原图像素一致；排序写入成功且资源请求数不增加。
