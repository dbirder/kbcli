# 创建时固定图标验收（0.11.0）

日期：2026-10-21。

## 原因与改动

旧 UI 在 render 时 attachFavicon，经 IntersectionObserver 触发来源路由；Reload 被识别为 refresh=true，Cache Storage 丢失或不可用时也会补来源请求。现在网格、分组缩略图和拖动预览只呈现 bookmark.icon 中的 WebP/文字。页面没有图标获取队列、刷新判定或后台 favicon fetch 路由，设置中的批量更新按钮移除。

获取仅存在于新建收藏表单和图标编辑的显式操作中。创建保存时等待本次获取，失败固定文字；普通改名、移动、修改分组及打开图标编辑器不获取图片。导入没有图片的旧记录固定为文字。

后台首次升级缺少图标的旧收藏时，只读取已有可读本机 Cache Storage 响应，转为 128px WebP；opaque、缺失、损坏或容量不足则固定文字，不联网补齐。已有自定义图片/文字不变。更新在本地队列中按 revision 校验，旧缓存保留。快照保存后，worker 重建不再读取旧图标来源。仍使用原 icon 字段，NAS 支持要求不增加（含图标同步沿用 kbcli 0.1.5）。
