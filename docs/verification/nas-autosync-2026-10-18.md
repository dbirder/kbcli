# NAS 自动同步验收摘要

验收日期：2026-10-18，时区 Asia/Shanghai。本文件记录这次已完成的验收，配置方法见 [自动同步说明](../nas-autosync.md)。

## 配置与身份

核心为 kbcli v0.1.1，调度器为独立 Compose 服务 kbcli-sync；每 5 秒观察工具写入、每 60 秒同步远端。网络错误退避从 15 秒开始，上限 300 秒。索引、操作日志、暂停标记与调度日志均在知识库 Git 目录外持久化。

实测确认，agent 身份执行带自动提交的同步会被接口拒绝。调度器使用操作者明确授权的服务用户身份，Hermes 继续使用原 agent 身份；没有放宽原有接口规则，也没有复制 root 私钥。控制入口通过 agent 身份做状态查询和恢复条件检查。
