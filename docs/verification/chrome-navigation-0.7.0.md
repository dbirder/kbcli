# 网站图标、网格和拖动验收（0.7.0）

日期：2026-10-19。

## 实现

- Chrome favicon 优先；识别默认地球图标后尝试网站自身 /favicon.ico。只使用 origin，不传收藏路径、查询或片段，图片 no-referrer。获取失败保留首字；内网服务或未提供图标的网站可能没有图片。
- 网站上图下文、两行名称，平时仅悬停/聚焦显示编辑和拖动手柄；整理模式提供排序按钮和目标分组。
- SortableJS 1.15.7 随扩展本地打包，自动滚动、独立手柄、5px 启动阈值与减少动效。方向键和原编辑分组入口作为替代。
- group.place / bookmark.place 单次原子保存，校验 revision、分组、后继 ID；沿用 navigation v1 与共享/备份协议，不修改 NAS。
